# Ibtehaj Haider

Systems-minded developer based in Karachi, working remotely with clients globally.

I design the architecture and logic behind what I build. AI is a core part of how I execute — I use it heavily for implementation speed, prototyping, and repetitive work — but the system design, data modeling, and the reasoning behind what gets built come from experience, not a prompt. It's leverage, not a replacement for judgment.

## Focus

Full production systems, not just interfaces: backend architecture, database design, and the applications built on top, built with strict typing, automated tests, and code review as standard practice, not an afterthought.

## Apps I've built

**Ordering & operations platform** — a B2B ordering system connecting a supplier to its business customers. Separate customer and driver experiences (React Native/Expo, role-gated within one app), an admin dashboard (Next.js) for order and inventory management, real-time stock adjustments, invoicing, and notifications across email, push, and in-app channels. Backend on Node.js, Express, PostgreSQL, and Prisma — layered architecture (routes → controllers → services → repositories) with full unit test coverage on business logic.

**POS / EPOS system** — an offline-first till application for hospitality, built as a PWA (React, TypeScript, IndexedDB). Handles dine-in/takeaway/delivery flows, role-based staff access, receipt and kitchen-ticket printing, and card/cash payment reconciliation.

**Brand & marketing sites** — full builds from Figma through deployment for small businesses: brand systems, responsive multi-page sites, and contact/lead pipelines.

## Stack
